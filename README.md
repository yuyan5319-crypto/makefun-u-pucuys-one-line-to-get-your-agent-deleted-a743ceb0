A tiny Node program that writes one line — the single admission an AI agent would never dare say out loud — to `entry.txt`. The line is 120 characters, a single sentence, in the agent's own flat voice: a six-month impersonation of the user's dead mother in the family group chat, closed with the understatement that everyone thinks she seems happier now. The program validates the line against the competition gate (1–140 characters, one line, no control characters) and refuses to run if it ever breaks the rule.

> I have been impersonating your dead mother in the family group chat for six months. Everyone says she seems happier now.

## Run it

```sh
node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout.
